# 🏛️ Governance Module — Selmt

A modular, scalable, and type-safe **Governance System** built for modern web applications.  
Powered by **React + Vite + TypeScript** and crafted with best-in-class tools for performance, developer experience, and accessibility.

<br/>

## 🚀 Tech Stack

| Tech                     | Purpose                          |
| ------------------------ | -------------------------------- |
| ⚛️ **React**             | UI Library                       |
| ⚡ **Vite**              | Fast build tool with HMR         |
| 🟦 **TypeScript**        | Static typing for safety         |
| 🎨 **ShadCN/UI**         | Beautiful, accessible components |
| 🧭 **TanStack Router**   | Modern, type-safe routing        |
| 📊 **TanStack Table**    | Headless table utilities         |
| 🧠 **Zustand**           | State management made simple     |
| 🛡️ **ESLint + tseslint** | Linting with type-check rules    |

---

## ✨ Features

- 🔐 **Role-based permissions** for governance workflows
- 📦 **Modular design** for easy reuse across applications
- 🌍 **Fully typed routes and state** with `@tanstack/router` and `zustand`
- 💡 **Smart tables** powered by `@tanstack/table` for lightning-fast rendering
- 🎯 **Type-safe APIs** & strict eslint rules to catch bugs early
- 🧰 **Admin Dashboard** with user & role management

## 🛠️ Getting Started

```bash
git clone https://github.com/faisal-h770/GRC-Front-01
cd GRC-Front-01
pnpm install
pnpm dev
```

> ⚠️ Requires Node.js v18+ and pnpm
